## 0. DB研究論文の読み方（毎回この順で見る）

| 見る場所 | チェックすること |
|---|---|
| Introduction の最後 | **何がわかっていなくて**、この研究で何を明らかにするのか（＝研究の「すき間」） |
| Methods：データ | どのDBか、期間、対象年齢 |
| Methods：対象者 | 組み入れ・除外基準、**インデックス日**（追跡の開始日）、ルックバック期間 |
| Methods：曝露 | 何を「使った」とみなしたか（薬剤コード、回数） |
| Methods：アウトカム | **病名だけか、病名＋薬剤か**。バリデーション研究を引用しているか |
| Methods：解析 | 調整した交絡因子、モデル（ロジスティック回帰／Cox回帰／Fine-Gray） |
| Results：Table 1 | 患者背景。比較する群の間で年齢や併存疾患がどれくらい違うか |
| Results：主結果 | 発生率、OR/HRとその95%信頼区間（**1をまたぐかどうか**） |
| Discussion：Limitations | 著者自身が認める弱点 → **自分の研究で改善できる点のヒント** |

## 1. テーマ②の中心論文

### 論文1 ⭐最重要：DeSCを用いたICI関連の内分泌障害（単一・複数）
- **出典**：*J Clin Endocrinol Metab* 2025; 111(1):54（PMID 40503677）
- **データ**：**DeSC**（日本の保険者DB、約1,240万人）。2014年〜2022年にICIを使った **12,978人**
- **アウトカム定義**：**ホルモン補充療法の開始**で定義
  - 甲状腺機能低下症 → レボチロキシン
  - 副腎不全 → ヒドロコルチゾン
  - 糖尿病 → インスリン
  - 甲状腺機能低下症は、甲状腺炎を経たものだけを数えている
- **主な結果**
  - 内分泌障害は、単一が **12.0%**、複数が **1.4%**
  - 最も多い組み合わせは「甲状腺機能低下症＋副腎不全」（1.3%）
  - 内分泌障害が起きた人のほうが**全生存が良かった**（irAEが出る人ほどICIが効いている、という既知の現象と一致）
  - 解析では、ICIの投与回数と投与期間を交絡因子として調整
- **自分のテーマとのつながり**
  - **②のアウトカム定義の型そのもの**。日本の保険者DBで「irAEを薬剤の開始で定義する」方法がすでに論文になっている → 先生に「実現可能です」と言える根拠
  - この論文の曝露は「ICIを使ったかどうか」。②ではここに「**自己免疫疾患の既往**」という患者要因を加える
- **本文で確認すること**
  - [ ] ICIを使う**前から**レボチロキシンを使っていた人をどう扱ったか（除外？）← ②の設計で最大の課題になる
  - [ ] 副腎不全の「ヒドロコルチゾン」は、ステロイド治療と区別できているか（補充量だけを数えた？）
  - [ ] 投与回数を調整すると、**イモータルタイムバイアス**（長く生きた人ほど投与回数が増える）は起きないか
  - [ ] 年齢分布（DeSCは高齢者が多い）

### 論文2：自己免疫疾患の既往はirAEのリスク因子か
- **出典**：*PLOS ONE* 2024（PMC11251620）
- **対象**：ICIを使った **478人**。このうち自己免疫疾患の既往ありは **28人（5.9%）**
- **主な結果**
  - 既往ありでirAEが起きやすい：**調整OR 2.52**
  - irAEによるICI中止も多い：**調整OR 3.32**
  - irAEが出た既往あり患者の **37.5%** で既往疾患が悪化（フレア）
- **読みどころ**：既往ありが28人しかいない → **信頼区間が広い**はず。**大規模DBで再検証する意義**がある
- **本文で確認すること**
  - [ ] 単施設か多施設か、どの国か
  - [ ] 既往の自己免疫疾患の種類（甲状腺疾患を含めているか？ 含めると「甲状腺irAE」と区別しにくい）

### 論文3：既往のある患者へのICIのシステマティックレビュー
- **内容**：17研究、883人の統合
  - 何らかのirAEは **53.5%**（新規のirAE 27.5%、既往疾患の悪化 34.3%）
  - 別の統合解析では、何らかのirAEのリスク比は **1.34**。重いirAE（グレード3以上）については結論が出ていない
- **読みどころ**：「既往があると**軽いirAE**は増えるが、**重いirAE**が増えるかはわからない」→ **重いirAEに絞った大規模研究**が求められている
- **テーマ②の新しさ**：日本の大規模DBで、**既往疾患の種類別**（関節リウマチ・乾癬・炎症性腸疾患など）に、**重いirAE**（入院、高用量ステロイド、免疫抑制薬の追加）のリスクを示す

### 論文4（参考）：JMDCを用いたICI開始後の心血管イベント
- **データ**：JMDC 2005〜2021年
- **主な結果**：心血管イベントはICIの初回処方から **180日以内**に多い。重大な心血管イベントまでの期間の中央値は **59日**
- **意味**：**JMDCでもICIのコホートが作れる**ことを示す前例

## 2. テーマ①の中心論文

### 論文5 ⭐：若年トリプルネガティブ乳がんでのペムブロリズマブと卵巣機能
- **出典**：*Breast Cancer Res Treat* 2025（PMID 40261555）
- **対象**：43歳未満のトリプルネガティブ乳がん患者。比較は「術前の化学療法＋ペムブロリズマブ」vs「化学療法のみ」
- **指標**：血中の**AMH**（卵巣予備能の指標）、FSH、エストラジオールを治療前後で測定
- **主な結果**
  - ペムブロリズマブを加えても、AMHの推移に**追加の影響は見られなかった**
  - ただし1年後にAMHが測定できないほど低かった割合は、併用群 **53%** vs 化学療法のみ **34%**
  - 著者自身が「より大規模な研究で確認が必要」と結論
- **読みどころ**
  - 「差がない」という結論と、53% vs 34%という数字の差が**一見矛盾**する → 症例数が少なく、統計的に有意にならなかっただけかもしれない（「差がない」ことの証明ではない）
  - AMHは**卵巣への直接ダメージ**を見る指標。ICIの**下垂体炎による中枢性の性腺機能低下**は別の経路で、この研究では評価されていない
- **本文で確認すること**
  - [ ] 各群の人数、統計手法
  - [ ] 両群で化学療法の内容（カルボプラチンの有無など）が同じか（**交絡**）

### 論文6：ICI治療後の男性の精巣機能
- **出典**：Boutros et al. *Clin Endocrinol* 2025（PMID 40653940）
- **対象**：メラノーマでICIを受けた19〜46歳の男性 **26人**（オーストラリア2施設、前向き）
- **主な結果**
  - 精子総数の中央値が **34%減少**、FSHが上昇（LHとテストステロンは保たれていた）
  - 1人（約4%）が**自己免疫性精巣炎**による持続的な無精子症
  - 著者は、**ICI開始前に妊孕性温存のカウンセリングを日常的に行う**ことを推奨
- **読みどころ**：まれだが重い影響が一定の割合で起きる → **まれな事象こそ大規模DBの出番**

### 論文7（背景）：ICIと女性の妊孕性・卵巣機能のシステマティックレビュー（2025）
- 動物実験では、ICIが卵巣や精巣に免疫細胞の浸潤や卵胞の減少を起こすことが示されている
- 併用療法（抗PD-1＋抗CTLA-4）では、下垂体炎が **8.8〜10.5%** と多い
- **ヒトの集団レベルのデータはほとんどない**

### テーマ①のまとめ：わかっていること・わかっていないこと
| わかっていること | わかっていないこと（＝研究のすき間） |
|---|---|
| 動物ではICIが性腺を傷つける | ヒトで**どのくらいの頻度**で性腺機能障害が起きるか |
| 少数例で、精巣炎・AMH低下の報告がある | **ICIを使った若年者の治療後の妊娠・出産**の実態 |
| 併用ICIでは下垂体炎が多い | 下垂体炎などの**内分泌irAEが性腺機能低下につながる割合** |

**DBでの実現可能性（正直な評価）**
- ICIが若年者の術前・術後療法に広がったのは2021〜2022年ごろから → **追跡期間がまだ短く、人数も少ない**可能性が高い
- まずは「**若年者でのICIの使用実態＋内分泌irAE（論文1の定義を流用）の発生率**」という**実態調査**から始め、将来的に妊娠のアウトカムまで広げる、という段階的な設計が現実的
