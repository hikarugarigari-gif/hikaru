# Step 1：保険者データベースの基礎知識

> 目的：明日の面談で「どのDBで何ができて、何ができないか」を自分の言葉で説明できるようにする。
> 対象：疫学・統計ほぼ初学者向け。まず全体像 → 用語 → 各テーマへの当てはめ、の順に読む。

## 1. そもそも「データベース（DB）研究」とは

- 患者さんを新たに集めて試験をする（臨床試験・前向き研究）のではなく、**すでに日常診療で発生した記録（リアルワールドデータ：RWD）** を後から解析する研究。
- 日本で最もよく使われる RWD は **レセプト（診療報酬明細書）** 由来のデータ。
  - 病院・薬局は、行った診療・処方した薬の代金を保険者（健保組合・国保など）に請求する。その請求書がレセプト。
  - 「何の病名で」「どの薬を」「いつ」「どれだけ」使ったか、が月単位・日単位で残る。
- **強み**：数十万〜数千万人規模、稀な有害事象（例：ニューモシスチス肺炎、顎骨壊死）や特殊な集団（妊娠期がん、小児がんサバイバー）を扱える。臨床試験で除外されがちな**高齢者**も多く含む。
- **弱み**：請求のための記録なので、**検査値・病期（ステージ）・PS・症状の重さ・自費診療**などは原則わからない。病名には「保険を通すための病名（いわゆるレセプト病名・疑い病名）」が混じる。

## 2. 日本の主な医療ビッグデータの比較

| | **JMDC**（保険者DB） | **DeSC**（保険者DB） | **MDV**（医療機関DB） | **NDB**（国のDB） |
|---|---|---|---|---|
| データ元 | 健康保険組合（会社員とその家族） | 健保組合＋**国保**＋**後期高齢者医療** | DPC病院（急性期病院）の診療データ | 全国のほぼ全レセプト |
| 規模（目安） | 累積 約2,000万人（2023年10月時点） | 約2,487万人（2025年3月末） | 実患者 約5,335万人（2025年8月末） | 日本全体 |
| 年齢構成 | **0〜74歳中心**、65歳以上が少ない | 若年〜**75歳以上**まで | 全年齢（病院受診者） | 全年齢 |
| 患者を追える範囲 | 加入中なら**どの病院・薬局を受診しても**追える | 同左 | **その病院の中だけ**（転院すると追えない） | 全国を追える |
| 家族の紐付け | **可能**（被保険者と被扶養者＝母子など） | 一部 | 不可 | 困難 |
| 検査値 | 健診結果のみ（一部） | 健診結果（一部） | **一部の病院で検査結果あり** | なし |
| 死亡 | ほぼ不明（脱退理由で一部） | 脱退理由で一部推定 | **院内死亡はわかる** | 一部 |
| 使いやすさ | 商用、研究実績多数 | 商用、近年急増 | 商用、研究実績多数 | 申請・審査が必要で重い |

### ポイント：「保険者DB」と「医療機関DB」の違い（面談で一番効く知識）

- **保険者DB（JMDC, DeSC）＝「人」を軸にしたデータ**
  - 保険に加入している限り、Aクリニックでの処方・B病院での入院・C薬局での調剤がすべて1人の患者IDでつながる。
  - → **外来で長期に追跡する研究**（例：化学療法後の感染症発症、何年も後の顎骨壊死、治療後の妊娠）に向く。
  - 欠点：転職・退職・75歳到達（JMDC）で**脱退すると追えなくなる**。死亡がわかりにくい。
- **医療機関DB（MDV）＝「病院」を軸にしたデータ**
  - 病院内の詳細（入院中の処置、一部検査値、院内死亡）が強い。
  - → **入院中の出来事、体重・検査値を使う研究**（例：膵がんの体重減少、妊娠期がんの分娩時アウトカム）に向く。
  - 欠点：他院を受診した分は見えない。

> 既存テーマを見ると、**「長期の外来追跡」→保険者DB、「病院内の詳細」→医療機関DB** と使い分けられていることがわかる。

## 3. DB研究で必ず出てくる用語（初学者向け）

### 3-1. データの中身に関する用語
| 用語 | 意味 | 例 |
|---|---|---|
| 傷病名コード（ICD-10） | 病名の国際分類コード | C50＝乳がん、B59＝ニューモシスチス症 |
| 疑い病名 | 検査のために付けた「〜の疑い」病名。**本当の病気ではない**ことが多い | 解析では除外するのが基本 |
| 医薬品コード（YJ/ATCコード） | 薬の識別コード | デキサメタゾン、デノスマブ |
| 診療行為コード | 処置・手術・検査・加算のコード | 化学療法加算、抜歯 |
| 観察期間（加入期間） | その人のデータが存在する期間 | 加入〜脱退 |

### 3-2. 研究デザインに関する用語
| 用語 | 意味（ひとことで） |
|---|---|
| **インデックス日（index date）** | 追跡の「スタート日」。例：初めてddACを投与した日 |
| **ルックバック期間（washout）** | インデックス日より前の一定期間（例：6か月）。この間に既に病気があった人を除外したり、併存疾患を調べたりする |
| **新規使用者デザイン（new-user design）** | その薬を「初めて使い始めた人」だけを対象にする。昔から使っている人を混ぜると偏るため |
| **アウトカム定義** | 「病気が起きた」とみなす条件。病名だけでなく **病名＋治療薬** の組み合わせで定義するのが一般的（例：PCP＝病名B59＋ST合剤/ペンタミジン治療） |
| **バリデーション（妥当性検証）** | そのアウトカム定義が本当に正しいか、カルテと突き合わせて確認した研究。**既存のバリデーション研究を引用できるか**が論文の説得力を大きく左右する |
| **交絡（confounding）** | 見かけの関連を作ってしまう第3の要因。例：「ステロイドを減らした群でPCPが少ない」→ 実は元気な人ほど減らしていたのかも |
| **多変量解析（ロジスティック回帰・Cox回帰）** | 複数の要因を同時に入れて、交絡を調整しながらリスク因子の影響を推定する方法 |
| **傾向スコア（propensity score）** | 「その治療を受ける確率」を計算し、似た者同士を比べることで交絡を減らす方法 |
| **オッズ比（OR）/ハザード比（HR）** | リスクが何倍か。ORはロジスティック回帰、HRはCox回帰で出る |
| **イモータルタイムバイアス** | 「〇〇を使った人」と定義するために、使うまで生きていた期間が有利に働いてしまう偏り。DB研究で頻出の落とし穴 |
| **競合リスク** | 目的のイベント（例：顎骨壊死）の前に死亡などが起きて観察できなくなること。終末期・高齢者研究で重要 |

### 3-3. 研究の「型」は大きく3つ
1. **実態調査（記述研究）**：どれくらいの人が・何を・どのくらい使っているか。
   - 例：光藤さん・荒船さんのテーマ、土屋先生の新規テーマの「実態調査」系。
   - 学部生が最初に取り組みやすく、論文にもなりやすい。
2. **リスク因子探索（関連の解析）**：どんな患者で有害事象が起きやすいか。
   - 例：顎骨壊死のリスク因子、PCPリスク。
   - 多変量解析が必要。**あなたが興味を持っている「薬と病気にフォーカスした」研究はこれ。**
3. **比較研究（治療Aと治療Bの比較）**：傾向スコア等を使い、因果に近い推論をめざす。
   - 例：ステロイドスペアリングあり vs なしでPCPリスクを比較（山田さんのテーマ）。

## 4. 保険者DBで「わかること・わからないこと」をがん薬物療法に当てはめる

| 知りたいこと | わかる？ | 補足 |
|---|---|---|
| どの抗がん薬をいつ投与したか | ◎ | 薬剤コードと日付からレジメン（ddAC等）を推定できる |
| 制吐薬・ステロイドの使用 | ◎ | 処方量・日数もわかる → 用量の計算が可能 |
| がん種 | ○ | 病名から。ただし疑い病名・レセプト病名に注意 |
| **ステージ・転移の有無** | △ | 直接はわからない。骨転移病名、骨修飾薬の使用などから代替推定 |
| 検査値（腎機能・血算） | ×〜△ | JMDC/DeSCは健診値のみ。MDVの一部病院で取得可 |
| 体重・BMI | △ | 健診・MDVの一部 |
| 有害事象（PCP、顎骨壊死など） | ○ | 病名＋治療で定義。**バリデーションの有無が鍵** |
| 死亡 | △ | 保険者DBでは不完全。終末期研究では工夫が必要 |
| 妊娠・出産 | ○ | 分娩・妊娠管理の診療行為コードで同定可。JMDCは**母子の紐付け**が可能 |
| **自費の医療（避妊目的のピル、卵子・精子凍結の多く）** | **×** | 保険外は記録されない。※凍結保存は自治体助成が中心で原則見えない |

> **面談で使える気づき**
> - 「若年がん患者の避妊期間遵守状況」は、避妊薬そのものは保険外で見えないので、**"治療終了後〇か月以内の妊娠"（分娩・妊娠関連コード）をアウトカム**にする設計になるはず → その定義を先生に確認すると良い。
> - 「高齢者」テーマが**保険者DB**とされているのは、**後期高齢者を含む DeSC** を想定している可能性が高い（JMDCは75歳以上がほぼいない）。
> - 「顎骨壊死」は数年単位の追跡と歯科受診の把握が必要 → 病院をまたいで追える保険者DB向き。**歯科レセプトが含まれるかどうか**は確認ポイント。

## 5. 薬学部ならではの視点（先生の研究室の色）

既存テーマを見ると共通点がある：
- **薬の「使い方」の最適化**（ステロイドを減らせるか＝スペアリング、制吐薬の適正使用）
- **薬が引き起こす有害事象のリスク**（PCP、顎骨壊死、生殖機能障害）
- **特別な集団での薬物療法**（小児・AYA・妊娠期・高齢者・終末期）

つまり「**どんな患者に・どの薬を・どう使うと・何が起きるか**」を、ガイドラインや臨床試験ではカバーしきれない実臨床データで示すのが研究室の軸。
→ あなたの希望（QOLより薬と病気にフォーカス）とよく合っている。
