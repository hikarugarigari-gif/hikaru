# 自分の研究の軸とテーマ候補（面談用の整理）

## 1. 自分の興味の軸

> **「臨床試験ではわからない患者集団で、抗がん薬の有害事象のリスク因子を定量的に明らかにし、添付文書やガイドラインの空白を埋めたい」**

| 自己分析 | 読み取れること |
|---|---|
| 薬害に気持ち悪さを感じる／授業でirAEが面白かった | 医薬品の**安全性（有害事象）**に関心 |
| 「リスク因子」に惹かれる | 「誰に起きやすいか」を**定量的に**明らかにしたい |
| 特別な患者 ＞ 添付文書・ガイドラインとのずれ ＞ 薬の組み合わせ | 臨床試験で除外された集団についての**エビデンスの空白** |
| 医師や制度を作る人に届けたい | 添付文書・ガイドラインに反映される種類のエビデンス |
| 相互作用・定量化しにくいテーマ・高齢者／終末期の治療は惹かれない | ハードなアウトカム、**治癒や長期生存を目指す治療の安全性**に関心 |

分野としては**薬剤疫学（医薬品安全性）**。研究室の方向性（支持療法・妊孕性・有害事象）と一致している。

## 2. テーマ候補

### ① 若年がん患者における免疫チェックポイント阻害薬（ICI）と生殖機能 ⭐
- **背景**：ICIは術前・術後療法として若年者にも使われるようになった（例：トリプルネガティブ乳がんの術前ペムブロリズマブ＋化学療法）。下垂体炎などの内分泌irAEは性腺機能に影響しうるが、根拠は総説・症例報告が中心で、**集団レベルのデータはほぼない**。
- **問い**：若年でICIを使った患者は、使わなかった患者と比べて、内分泌irAE・性腺機能低下・治療後の妊娠に差があるか？ そのリスク因子は？
- **DB**：JMDC（若年者が多く、母子の紐付けも可能）
- **懸念**：がんのサブタイプがレセプトにないので、レジメンから対象を推定する必要がある。症例数が足りるか。

### ② 自己免疫疾患の既往がある患者でのICIとirAE
- **背景**：自己免疫疾患のある患者は、ICIの臨床試験で除外されてきた。
- **問い**：関節リウマチ・甲状腺疾患などの既往がある患者で、irAEや持病の悪化は増えるか？ どの既往疾患・どのICIでリスクが高いか？
- **DB**：JMDC
- **アウトカム定義**：治療薬の新規開始で定義できる（甲状腺ホルモン薬、ヒドロコルチゾンの補充、高用量ステロイド、インスリンなど）→ **実現可能性が高い**。

### ③ 抗がん薬の種類と顎骨壊死のリスク因子（先生の新規テーマ）
- **問い**：骨修飾薬を使うがん患者で、併用する抗がん薬（血管新生阻害薬・mTOR阻害薬・ステロイドなど）や歯科受診によってリスクは変わるか？
- 副作用報告DB（JADER/FAERS）で出ているシグナルを、**コホート研究で検証**する位置づけ。

### ④ 膵がん：根治を目指す治療の安全性
保険者DB（JMDC）はほぼ75歳未満の集団なので、**働く世代の膵がん**が自然に対象になる。
- **④-a 術前・術後化学療法**（ゲムシタビン＋S-1、術後S-1など）：重い有害事象と治療完遂のリスク因子は？ 膵切除後の糖尿病や消化酵素不足（膵消化酵素補充薬の使用）は影響するか？
- **④-b イリノテカン系レジメン**（mFOLFIRINOX、ナノリポソーム型イリノテカン）：UGT1A1遺伝子検査の実施の有無と、発熱性好中球減少症の関連は？ 薬理遺伝学（ファーマコゲノミクス）が実臨床でどう生かされているか。
- **④-c がん関連の静脈血栓塞栓症**：膵がんはVTEのリスクが最も高いがん種の一つ。抗凝固薬（DOAC）による出血のリスク因子は？
- **確認事項**：研究室にはD1 宮崎さんの膵がんテーマ（MDV、体重減少と治療継続性）がある。重なりを避けるか、連携できるか。

## 3. 面談での伝え方の例
> 「自分の興味は、臨床試験でカバーされない患者での抗がん薬の安全性、特にリスク因子の定量化にあると整理しました。その上で、授業で面白いと思ったirAEと研究室の妊孕性のテーマを掛け合わせた①、実現可能性の高い②、膵がんの根治を目指す治療の安全性を見る④を考えてきました。DBでどこまでできるかご相談したいです。」
