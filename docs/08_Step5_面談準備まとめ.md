## 1. 最初に話すこと（1分）

> 「自分の興味を整理したところ、**臨床試験ではわからない患者集団で、抗がん薬の有害事象のリスク因子を定量的に明らかにし、添付文書やガイドラインの空白を埋める**研究がしたいと考えました。授業でirAEが面白いと思ったこともあり、**ICIの安全性**を軸に候補を考えてきました。また、治療がすぐ変わる特定のレジメンより、**薬剤クラスや患者要因についての問い**のほうが、時間がたっても価値が落ちないと考えています。」

## 2. テーマ候補（優先順）

### ① 本命：若年がん患者へのICIと生殖機能
- **背景**：ICIは術前・術後療法として若年者にも広がった（例：トリプルネガティブ乳がんの術前ペムブロリズマブ）。性腺への影響は動物実験・少数例の報告のみで、**集団レベルのデータはほぼない**
- **先生の研究との接続**：2021年の *Future Oncol* 論文（JMDC）で「無月経リスクが不明な抗がん薬が多く使われている」と示された → **ICIは今まさにリスク不明の薬**
- **根拠**：Kamitani 2025（DeSC）で、**副腎不全（≒下垂体炎）は若いほど多い**（10歳若いごとに約1.2倍）。下垂体炎 → 中枢性の性腺機能低下の可能性
- **案**：JMDCで生殖年齢（15〜45歳）のICI使用者を抽出 → まずは**使用実態＋内分泌irAEの発生率**（実態調査）→ 将来的に**治療後の妊娠**（JMDCの妊娠アルゴリズム・母子紐付け）
- **懸念**：術前・術後のICIは2021〜2022年以降で、**追跡期間と症例数が足りるか**

### ② 実現可能性が高い：自己免疫疾患の既往がある患者でのICIとirAE
- **背景**：既往のある人は臨床試験で除外されてきた。統合解析では軽いirAEは増える（リスク比1.34）が、**重いirAEが増えるかは結論が出ていない**
- **根拠**：Kamitani 2025で「**もともとの甲状腺機能低下症 → 1型糖尿病のリスク2.54倍**」
- **案**：JMDC（またはDeSC）で、既往の自己免疫疾患（関節リウマチ・乾癬・炎症性腸疾患・橋本病など）を**種類別**の曝露とし、**重いirAE**を発生までの時間で解析
- **アウトカム定義**：内分泌irAEはホルモン補充薬の開始（Kamitani 2025の定義を流用）。内分泌以外の重いirAEは高用量プレドニゾロン／メチルプレドニゾロン、インフリキシマブ・ミコフェノール酸の追加など
- **設計上の論点**：アウトカムごとに既往のある人を除外する／**制吐目的のデキサメタゾン**とirAE治療のステロイドを区別する／既往疾患の悪化（フレア）と新しいirAEを区別する

### ③ 安全策：抗がん薬の種類と顎骨壊死のリスク因子（先生の新規テーマ）
- 骨修飾薬の使用者で、併用する抗がん薬（血管新生阻害薬など）・歯科処置によるリスクを、**副作用報告DBのシグナルからコホートで検証**
- 先行研究：静岡国保DB研究（2026）、NDB研究（Ishimaru 2022）

## 3. 先生に聞きたいこと

### A. データ・環境（実現可能性）
1. 研究室で使えるDBはどれか（JMDC／DeSC／MDV）。**データの最新期間**はいつまでか（2024年まで入っているか）→ テーマ①の実現可能性に直結
2. JMDCの**母子紐付け**、**妊娠同定アルゴリズム**は研究室で使えるか。治療後の妊娠のアウトカムにも使えるか
3. 解析環境（SAS／R／Python、データの置き場所、作業ルール）

### B. テーマの方向性
4. テーマ①は症例数が少ないかもしれない。まず「実態調査」から始めるのは学部の卒業研究として妥当か
5. テーマ②で「重いirAE」をレセプトでどう定義するのが良いか。研究室で使ってきた定義やバリデーション研究はあるか
6. 制吐目的のデキサメタゾンとirAE治療のステロイドは、薬剤と用量でどう区別すると良いか
7. 3つの候補のうち、研究室の今後の方向性（科研費の妊娠・抗がん薬の研究など）と最も合うのはどれか

### C. 先生の研究について
8. 2023年の論文で妊娠中の抗がん薬曝露は13人だったが、科研費の研究ではどうやって症例数を確保しているのか
9. 自然言語処理の研究で使っているカルテデータは、レセプトDBと組み合わせられるのか

### D. 研究室での進め方
10. 先輩方（山本さん・山田さん・宮崎さん）とテーマが重ならないか。逆に一緒に進められる部分はあるか
11. 学部生のうちに身につけておくべき統計や疫学の基礎（おすすめの教科書など）
12. 卒業研究のスケジュール（いつまでにテーマ確定、倫理審査、解析、学会発表など）

## 4. 面談で出てきそうな用語（30秒で説明できるように）
| 用語 | ひとことで |
|---|---|
| 新規使用者デザイン | その薬を初めて使い始めた人だけを対象にする |
| インデックス日／ルックバック期間 | 追跡の開始日／その前の、既往や併用薬を調べる期間 |
| アウトカム定義・バリデーション | 「起きた」とみなす条件と、その正しさの検証 |
| イモータルタイムバイアス | 「◯◯が起きた群」に入るまで生きていることによる偏り |
| 競合リスク | 目的のイベントの前に死亡などが起きて観察できなくなること（Fine-Grayモデル） |
| 時間依存性共変量 | 追跡途中で変わる変数を、変わった時点から反映する方法 |
