# 精読：Kamitani et al. ICI関連の単一・複数の内分泌障害（DeSC）

> Kamitani F, Nishioka Y, et al. Multiple or Single Endocrine Abnormalities Associated With Immune Checkpoint Inhibitors.
> *J Clin Endocrinol Metab* 2026;111(1):54–61（2025年6月オンライン公開）. PMID 40503677. オープンアクセス
> 著者：**奈良県立医科大学**の糖尿病・内分泌内科と公衆衛生学（野田龍也、今村知明らのレセプト研究で有名なグループ）

---

## 1. 一言でいうと
日本の保険者DB（DeSC）で、ICIを使った約1.3万人を調べた。**ホルモン補充薬の処方**で内分泌のirAEを定義し、その頻度・リスク因子・生存との関連を示した。

## 2. 研究の骨組み（PECO）

| 要素 | 内容 |
|---|---|
| **P（対象）** | DeSC（約1,240万人）のうち、2014年4月〜2022年2月にICIを使った18歳以上 **12,978人** |
| **E（曝露）** | ICIの種類：抗PD-1単剤（75.5%）、抗PD-L1単剤（17.9%）、抗PD-1＋抗CTLA-4併用（3.4%）、抗CTLA-4単剤、抗PD-1→抗PD-L1の順次使用 |
| **O（アウトカム）** | ICI開始後に新たに起きた内分泌障害（甲状腺機能低下症、副腎不全、1型糖尿病） |
| 患者背景 | 年齢の中央値 **73歳**、男性 **74.6%**、非小細胞肺がん 52.7%、胃がん 22.3%。追跡期間の中央値 356日 |

## 3. 方法のポイント（ここが一番勉強になる）

### 3-1. 対象者の選び方
- ICI初回投与の**前に180日以上**のデータがある人だけ → ルックバック期間。過去にICIを使った人や、もともと内分泌障害がある人を見分けるため
- ICI初回投与の**後に180日以上**のデータがある人だけ（死亡は除く）
- **それぞれの内分泌障害の解析では、ICI前にすでにその治療を受けていた人を除外** ← 私が気にしていた「もともとレボチロキシンを飲んでいた人をどう扱うか」の答え。**アウトカムごとに、既往のある人を除外**している

### 3-2. アウトカムの定義（なぜ病名を使わないのか）
レセプトの病名（「下垂体炎」「甲状腺炎」など）は実際の病態を正確に表さないことが多いので、**補充療法の処方**で定義した。

| 内分泌障害 | 定義 | 発症日 |
|---|---|---|
| 甲状腺機能低下症 | 病名＋**レボチロキシン**の処方 | レボチロキシンの初回処方日 |
| 副腎不全 | **ヒドロコルチゾン**の処方 | ヒドロコルチゾンの初回処方日 |
| 1型糖尿病 | 病名＋インスリン＋**1型糖尿病に限定された在宅自己注射の指導管理料** | 指導管理料の初回算定日 |

- **ヒドロコルチゾンを選んだのがうまい**：irAEの治療（高用量ステロイド）では、普通プレドニゾロンやメチルプレドニゾロンが使われる。ヒドロコルチゾンは主に**補充療法**で使われるので、「補充が必要な副腎不全」を拾いやすい
- 1型糖尿病の定義は、別の研究で**感度0.72・特異度1.00**と検証済み（バリデーション研究の引用）
- **弱点**：中枢性（下垂体炎）か原発性（甲状腺・副腎そのもの）かは区別できない。ただし、ICIによる副腎不全の90%以上は下垂体炎によるものなので、副腎不全 ≒ 下垂体炎とみなしている

### 3-3. 解析
- **リスク因子**：ロジスティック回帰。調整した因子は年齢・性別・ICIの種類・がん種・Charlson併存疾患指数
- **生存**：Cox回帰。**イモータルタイムバイアス**対策として、ICIの投与回数と投与期間を調整
- 統計ソフトはSPSS

## 4. 結果

### 4-1. 頻度
| | 全体 | 抗PD-1単剤 | 抗PD-L1単剤 | **抗PD-1＋抗CTLA-4併用** |
|---|---|---|---|---|
| 甲状腺機能低下症 | **10.5%** | 9.9% | 8.7% | **19.6%** |
| 副腎不全 | **4.6%** | 4.7% | 2.2% | **17.0%** |
| 1型糖尿病 | **0.6%** | 0.5% | 0.3% | **2.8%** |

- 単一の内分泌障害は12.0%、複数は1.4%。複数で最も多いのは「甲状腺機能低下症＋副腎不全」（1.3%）
- **甲状腺機能低下症の7人に1人が副腎不全も起こした**。1型糖尿病の15人に1人が副腎不全も起こした → 副腎クリーゼは命に関わるので、臨床的に重要なメッセージ

### 4-2. リスク因子（調整オッズ比）
| 内分泌障害 | リスクを上げる因子 | リスクを下げる因子 |
|---|---|---|
| 甲状腺機能低下症 | 女性（OR 1.17）、併用療法（OR 1.91） | 抗PD-1→抗PD-L1の順次使用（OR 0.44） |
| 副腎不全 | **若い**（10歳上がるごとにOR 0.84）、**男性**（女性でOR 0.81）、併用療法（OR 3.35） | 抗PD-L1単剤（OR 0.48）、順次使用（OR 0.36） |
| 1型糖尿病 | 併用療法（OR 3.78）、**もともとの甲状腺機能低下症（OR 2.54）** | — |

### 4-3. 生存
- 内分泌障害が起きた人のほうが生存が良かった
  - 甲状腺機能低下症：調整HR 0.65、副腎不全：調整HR 0.60
  - 複数：調整HR 0.39、単一：調整HR 0.65（vs なし）
- 解釈：irAEが出る人ほどICIが効いている、という既知の現象と一致する

## 5. 批判的に読む（面談で話せるポイント）

1. **「ICI開始後180日以上のデータがある人」に限定している**
   - これは**未来の情報を使って対象者を選んでいる**ことになる。180日以内に保険を脱退した人（転院・転居など）が除外されるので、偏りが生じうる
2. **イモータルタイムバイアスへの対策が十分か**
   - 内分泌障害が起きるまで生きていた人だけが「内分泌障害あり」群に入るので、その群の生存が有利に見える
   - 著者は「投与回数・期間を調整」したが、より標準的な方法は**時間依存性共変量**（内分泌障害が起きた時点から「あり」群に移す）や**ランドマーク解析**。投与回数は治療の結果でもあるので、調整に使うのは議論の余地がある
3. **リスク因子の解析がロジスティック回帰**
   - 追跡期間の長さが人によって違う（早く亡くなった人はirAEが起きる前に観察が終わる）。**死亡を競合リスクとした生存時間解析**（Fine-Grayモデル）のほうが適切かもしれない
4. **高齢者中心のデータ**（年齢の中央値73歳）
   - DeSCは後期高齢者を含むため。**若年者の結果は、この論文からはほぼわからない**

## 6. 自分のテーマへの示唆 ⭐

### テーマ②（自己免疫疾患の既往とirAE）への示唆
- **「もともとの甲状腺機能低下症 → 1型糖尿病のリスク2.54倍」**という結果は、まさに「**既往の自己免疫疾患が別のirAEのリスクを上げる**」ことを示している。テーマ②の**仮説を支える根拠**として使える
- この論文では既往は1つの共変量にすぎない → **既往の自己免疫疾患を主な曝露**にして、種類別（関節リウマチ・乾癬・炎症性腸疾患・橋本病など）に体系的に調べる研究には新しさがある
- **設計で使える工夫**
  - アウトカムごとに、その既往がある人を除外する（この論文の方法をそのまま使える）
  - 内分泌以外の重いirAE（大腸炎・肺炎・肝炎など）は、**高用量のプレドニゾロン／メチルプレドニゾロン**や、**インフリキシマブ・ミコフェノール酸の追加**で定義することが考えられる
  - そのとき、**制吐目的のデキサメタゾン**（化学療法との併用レジメンで使う）をirAE治療と誤認しないよう、薬剤と用量で区別する必要がある → **制吐療法に詳しい土屋先生の専門とつながる論点**
  - 既往疾患の「悪化（フレア）」と「新しいirAE」を区別する方法（例：既往疾患の治療薬の増量）は要検討

### テーマ①（若年者とICI・生殖機能）への示唆
- **副腎不全（≒下垂体炎）は若い人ほど起きやすい**（10歳若いごとにリスクが約1.2倍）
- 下垂体はLH・FSHを通じて**性腺もコントロールしている** → 下垂体炎が起きた若年者では、**中枢性の性腺機能低下**も起きうる
- つまり、「若年者 → 下垂体炎が多い → 生殖機能への影響」という**テーマ①の筋道を支える根拠**になる
- ただしDeSCは高齢者中心なので、テーマ①には**JMDC**（若年者が多い）が向いている

## 7. この論文から学んだ用語
| 用語 | 意味 |
|---|---|
| Charlson併存疾患指数（CCI） | 併存疾患の重さを点数化したもの。DB研究で交絡調整によく使う |
| 感度・特異度 | 感度＝本当の患者を正しく拾える割合、特異度＝患者でない人を正しく除外できる割合 |
| 調整ハザード比（aHR） | 交絡因子を調整したうえでの、イベントが起きる速さの比。1より小さいとリスクが低い |
| イモータルタイムバイアス | 「◯◯が起きた群」に入るには、それが起きるまで生きている必要があるために生じる偏り（Suissa 2008が古典的な論文） |
| 時間依存性共変量 | 追跡の途中で値が変わる変数（例：irAEの発生）を、変わった時点から反映させる解析方法 |
